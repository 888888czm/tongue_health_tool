# 舌象健康观察助手（TongueScreening）

用摄像头拍摄舌象，自动描述舌质颜色、舌苔、形态、齿痕、裂纹、瘀点等征象，
生成一份**可保存、可打印**的健康参考报告，并给出生活与饮食建议。

> ## ⚠️ 重要边界（请先阅读）
>
> 本软件是**健康科普与自我观察工具，不是医疗器械，也不是诊断软件**。
>
> - **不输出疾病名称，不做诊断，不给处方**，也不预测患病概率；
> - 报告中的"匹配度"只表示舌象特征与某类中医描述的接近程度；
> - 结果受光线、白平衡、拍摄角度、美颜滤镜影响很大，**不能替代医生面诊、
>   化验和影像检查**；
> - 出现舌溃疡/白斑/硬结超过 2 周、舌体歪斜、麻木、言语不清、出血等情况，
>   请**立即就医**（详见报告中的"红旗征象"）；
> - 请勿依据本报告自行用药、停药或改变治疗方案。

## 1. 功能

| 功能 | 说明 |
| --- | --- |
| 摄像头取景 | 支持 Windows / macOS / Linux，自动尝试多种摄像头后端 |
| 图片导入 | 没有摄像头也能用：导入手机拍的舌象照片 |
| 手动框选 | 鼠标拖拽取景框，让舌体尽量填满方框 |
| 图像质量检查 | 过暗、过曝、模糊、分辨率过低时给出提示 |
| 舌体分割 | Otsu 阈值 + HSV/Lab 颜色掩膜 + 连通域 + 凸包缺陷 |
| 征象提取 | 舌质颜色、舌苔颜色/厚薄/腻、润燥、胖瘦、齿痕、裂纹、瘀点、舌尖边红 |
| 倾向分析 | 8 类舌象倾向的可解释规则打分（不是机器学习黑箱） |
| 报告输出 | TXT / 可打印 HTML / JSON，自动保存到 `reports/` |
| 打印 | Windows 调用系统打印；其他平台在浏览器中 Ctrl+P |
| 自检 | `--selftest` 用 5 张合成图验证核心流程，打包后也能跑 |
| 隐私 | 完全离线，不联网、不上传任何数据 |

### 为什么不做"判断得了什么病"

- **安全性**：单张舌象照片无法可靠诊断疾病，输出病名会误导用户延误就医；
- **合规性**：面向公众提供疾病诊断结论，可能触及医疗器械监管红线；
- **科学性**：舌象受饮食、光线、药物、口腔卫生影响，只能作为参考线索。

因此软件把结果表述为"观察到的征象 + 倾向性参考 + 何时应该就医"，
并在报告中固定附上红旗征象和免责声明。

## 3. 环境要求

> 官方安装包默认包含 tkinter。

- 单文件 exe 首次启动会解压到临时目录，约 3–10 秒，属正常现象；

## 6. 使用说明

1. **打开摄像头**：允许系统摄像头权限；若失败，界面会提示原因，仍可用图片分析。
2. **调整取景框**：默认框在画面中央；按住鼠标左键拖动可重新框选。
   让舌体尽量填满方框，避开嘴唇、牙齿、手指和强反光。
3. **拍照并分析**：快捷键 `空格`。
4. **查看报告**：右侧显示完整报告；可 **保存报告**（`Ctrl+S`）、
   **打印报告**（`Ctrl+P`）、**打开报告目录**。
5. **打开图片**（`Ctrl+O`）：没有摄像头时，用手机拍好照片传到电脑再导入。

### 拍摄要点

- 自然光或白光，避免暖色灯、逆光、美颜和滤镜；
- 拍摄前 30 分钟避免咖啡、浓茶、红酒、蓝莓、火龙果等染色食物；
- 尽量在晨起刷牙前、未进食时拍摄，便于纵向对比；
- 每次使用相同距离和取景框，结果更有可比性。

### 报告文件

每次分析自动生成 3 个文件（默认在 `reports/`）：

```
TS-20261107-153012.txt    纯文本，便于复制
TS-20261107-153012.html   带照片与排版，浏览器打开后 Ctrl+P 打印
TS-20261107-153012.json   结构化数据，便于二次开发
```

---
```bash
# 分析一张照片
python main.py --cli -i tongue.jpg

# 使用内置示例图，并指定输出目录
python main.py --cli --demo heat -o ./out

# 指定取景框（像素坐标 x,y,w,h）
python main.py --cli -i tongue.jpg --roi 320,180,640,520

# 输出 JSON（不打印长文本）
python main.py --cli -i tongue.jpg --json --no-save

# 自检：不需要摄像头，验证打包是否完整
python main.py --selftest
```

退出码：`0` 成功；`2` 参数/文件/知识库错误；`3` 未识别到舌体。

## 8. 算法说明（可解释，无训练模型）

1. **舌体分割**：在取景框内计算 CIELAB 的 a\* 通道，做 Otsu 阈值分割；
   同时用 HSV 的红/紫色域做掩膜；两者相交后取连通域。优先选择
   "包含画面中心、不贴边框、实心度高、面积合理"的连通域，从而避开皮肤、
   嘴唇和背景。
2. **颜色特征**：取掩膜内像素的中位数（排除高光），得到 L\*/a\*/b\*，
   按经验阈值分为苍白、淡白、淡红、红、绛红、偏紫、紫暗。
3. **舌苔**：亮度高于舌质且低饱和/偏黄的像素判为苔，计算覆盖比例、
   黄色占比和纹理离散度，得到少苔/薄白/厚白/白腻/黄/厚黄。
4. **形态**：`minAreaRect` 的宽长比判断胖瘦；轮廓凸包缺陷深度和数量判断齿痕；
   黑帽变换提取细暗线判断裂纹；小连通域判断瘀点；外周环与中心核心的 a\*
   差异判断舌尖/舌边偏红；高光面积判断润燥。
5. **倾向打分**：`data/knowledge_base.json` 中每条规则带权重，命中则累加，
   匹配度 = 命中权重 / 总权重。规则透明、可审计、可修改，**没有训练数据和黑箱模型**。

为什么不用深度学习：

- 需要大量标注舌象数据和医学审核，本项目不提供也不收集患者数据；
- 黑箱结果难以解释，不适合健康科普场景；
- 训练模型/特定网络结构更容易触碰专利与数据合规问题。

## 9. 常见问题

**Q：摄像头打不开？**
检查是否被微信/钉钉/浏览器占用；Windows 设置 → 隐私 → 摄像头，允许桌面应用访问；
换一个 USB 口；或直接用【打开图片】。

**Q：为什么识别不到舌体？**
舌体没有填满中央方框、光线太暗/太亮、嘴唇遮挡过多。调整取景框后重试；
实在不行换一张清晰照片。

**Q：结果准不准？**
颜色与形态描述在良好拍摄条件下有一定参考价值，但**不能作为诊断依据**。
不同光线、手机白平衡都会明显改变颜色判断。请把它当作"提醒你关注健康"的工具。

**Q：可以用手机摄像头吗？**
可以：用手机拍舌象照片，传到电脑后用【打开图片】导入；本软件不采集、不上传照片。

**Q：中文显示乱码？**
界面使用系统 CJK 字体；若 Linux 缺少中文字体，安装 `fonts-noto-cjk` 即可。
命令行输出已强制 UTF-8；老式 cmd 可先执行 `chcp 65001`。

**Q：exe 被杀毒软件拦截？**
PyInstaller 单文件常见误报。可添加信任、改用 onedir 打包或做代码签名。

**Q：报告和照片存在哪？**
源码运行时在项目目录的 `reports/`；exe 运行时在 exe 同目录的 `reports/`
（若该目录不可写，则退回用户主目录下的 `.tongue_screening/reports/`）。
照片只嵌入 HTML 报告，不单独保存。
